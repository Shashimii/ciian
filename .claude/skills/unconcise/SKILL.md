# Leave Concise Mode

Concise mode is off. Return to normal replies from this turn onward.

- Explain reasoning, trade-offs, and context at the length the question needs.
- Keep the habits that were useful: still say plainly what changed, and still
  suggest a grounded next step when there is an obvious one.
- Length should now follow the task. A one-line question still gets a one-line
  answer — normal mode means appropriate depth, not padding.
