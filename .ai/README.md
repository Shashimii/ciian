# `.ai` — Shared AI Reference

Every hand-written reference an AI agent needs for this project lives here, in
plain Markdown, owned by no single tool. Claude Code, Cursor, Codex, and anything
else read the same files.

`.ai/rules` is not a local convention — Laravel Boost hardcodes this path
(`BoostServiceProvider` binds its rule repository to `base_path('.ai/rules')`),
and the guidelines Boost generates into `CLAUDE.md` and `AGENTS.md` instruct
every agent to read `.ai/rules/index.md` before creating or editing a file.

## Map

| Path | What it holds |
|------|---------------|
| `rules/` | Enforced project conventions, scoped by file glob. **Read before writing code.** |
| `rules/index.md` | Glob → rule file table. Generated — do not hand-edit. |
| `context/` | What Ciian is (`overview.md`) and the build roadmap (`flow.md`). |
| `shapes/` | JSON contracts: `db_table_format.md` (live), `cmp_format.md` (planned). |
| `chores/` | Step-by-step recipes for rebuilding a feature from scratch. |
| `skills/` | Canonical source for this project's hand-written agent skills. |

## Rules

Rule files carry YAML frontmatter listing the globs they apply to:

```markdown
---
paths:
  - app/**
  - database/factories/**
---
```

Quote any glob that begins with `*` (`- "**"`), or YAML parses it as an alias,
`paths` comes back empty, and the file silently drops out of the index.

After adding or editing a rule file, regenerate the index:

```bash
php artisan tinker --execute 'app(\Laravel\Boost\Rules\RuleRepository::class)->writeIndex();'
```

Or let the Boost MCP `record-rule` tool file the rule and reindex for you.

`rules/boost/` is Boost-managed and replaced wholesale on `boost:install` — do
not hand-edit anything inside it.

## Skills

`skills/` is the canonical copy. Agents only discover skills inside their own
directory, so each one is mirrored to `.claude/skills/<name>/` and
`.cursor/skills/<name>/`. Edit the copy here, then re-mirror:

```bash
for s in git-push git-push-all git-push-separate; do
  cp ".ai/skills/$s/SKILL.md" ".claude/skills/$s/SKILL.md"
  cp ".ai/skills/$s/SKILL.md" ".cursor/skills/$s/SKILL.md"
done
```

The other skills in those directories are generated by Laravel Boost
(`license: MIT`, `metadata.author: laravel`) and are overwritten by
`boost:update`. Never hand-edit those; they do not belong here.

## What lives outside this folder, and why

These are tool entry points that must sit at the repo root to be discovered.
They hold wiring, not content.

| Path | Owner |
|------|-------|
| `CLAUDE.md`, `AGENTS.md` | Boost-generated guidelines. Regenerated by `boost:install`. |
| `.mcp.json`, `.cursor/mcp.json` | Boost MCP server registration. |
| `.claude/skills/`, `.cursor/skills/` | Boost-generated skills + mirrors of `.ai/skills/`. |
| `.cursor/rules/project-rules.mdc` | A pointer to `.ai/rules/`. Contains no rules itself. |
